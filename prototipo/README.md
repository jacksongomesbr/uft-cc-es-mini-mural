# Protótipo navegável

Abra o `index.html` em qualquer navegador; ele não precisa de internet nem de instalação.
Comece por "começar pela tela de entrar" e toque nos elementos sublinhados ou com borda para seguir o fluxo do UC-01.
As telas de recusa também estão listadas na primeira tela, e cada tela diz, no rodapé, a que critério corresponde.
